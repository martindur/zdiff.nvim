=============================================================================
CONTENTS                                                        *zdiff-contents*

1. Commands ..................................................... |zdiff-commands|
2. Mappings ..................................................... |zdiff-mappings|

=============================================================================
COMMANDS                                                        *zdiff-commands*

                                                        *:Zdiff*
:Zdiff                  Open the uncommitted change summary.

                                                        *:ZdiffToggle*
:ZdiffToggle            Expand or collapse the file under the cursor.

                                                        *:ZdiffOpen*
:ZdiffOpen              Open the source location under the cursor. Use CTRL-O
                        to return to the diff and CTRL-I to move forward again.

                                                        *:ZdiffRefresh*
:ZdiffRefresh           Reload uncommitted changes.

=============================================================================
MAPPINGS                                                        *zdiff-mappings*

The diff buffer maps <Tab> to toggle a file and <CR> to open source.

The following <Plug> mappings are available for user configuration:

    <Plug>(zdiff-toggle)
    <Plug>(zdiff-open)
    <Plug>(zdiff-refresh)

All other motions and operators retain their normal Neovim behavior.
