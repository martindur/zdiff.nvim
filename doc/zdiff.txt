*zdiff.txt*                    Review uncommitted Git changes

=============================================================================
CONTENTS                                                        *zdiff-contents*

1. Commands ..................................................... |zdiff-commands|
2. Configuration ........................................... |zdiff-configuration|

=============================================================================
COMMANDS                                                        *zdiff-commands*

                                                        *:Zdiff*
:Zdiff [ref]            Open the uncommitted change summary, or changes since
                        the merge base of [ref] and HEAD. Existing comparison
                        buffers are refreshed and reused.

                                                        *:ZdiffToggle*
:ZdiffToggle            Expand or collapse the file under the cursor.

                                                        *:ZdiffOpen*
:ZdiffOpen              Open the source location under the cursor. Use CTRL-O
                        to return to the diff and CTRL-I to move forward again.

                                                        *:ZdiffRefresh*
:ZdiffRefresh           Reload the current comparison.

ZdiffOpen, ZdiffToggle, and ZdiffRefresh are buffer-local commands. They only
exist inside the zdiff buffer that owns their review session.

=============================================================================
CONFIGURATION                                              *zdiff-configuration*

Zdiff defines no keymaps. Configure buffer-local mappings with a FileType
autocmd if desired: >lua

    vim.api.nvim_create_autocmd("FileType", {
      pattern = "zdiff",
      callback = function(event)
        local opts = { buffer = event.buf, silent = true }

        vim.keymap.set("n", "<CR>", "<cmd>ZdiffOpen<cr>", opts)
        vim.keymap.set("n", "<Tab>", "<cmd>ZdiffToggle<cr>", opts)
        vim.keymap.set("n", "R", "<cmd>ZdiffRefresh<cr>", opts)
        vim.keymap.set("n", "q", "<cmd>bdelete<cr>", opts)

        vim.keymap.set("n", "m", function()
          if vim.b.zdiff.base == "" then
            vim.cmd("Zdiff main")
          else
            vim.cmd("Zdiff")
          end
        end, opts)
      end,
    })
<

These are suggested mappings, not defaults. Unmapped keys retain their normal
Neovim behavior.

Each zdiff buffer exposes |b:zdiff| with these fields: >lua

    vim.b.zdiff.root -- repository root
    vim.b.zdiff.base -- empty for uncommitted, otherwise the requested ref
