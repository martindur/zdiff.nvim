COMMANDS                                                        *zdiff-commands*

                                                        *:Zdiff*
:Zdiff [ref]            Open the uncommitted change summary, or changes since
                        the merge base of [ref] and HEAD. Existing comparison
                        buffers are refreshed and reused.

Returning to a comparison with CTRL-O or a buffer switch does not refresh it.
Use :ZdiffRefresh or reopen it through :Zdiff to reload its contents.

                                                        *:ZdiffToggle*
:ZdiffToggle            Expand or collapse the file under the cursor.

                                                        *:ZdiffOpen*
:ZdiffOpen              Open the source location under the cursor. Use CTRL-O
                        to return to the diff and CTRL-I to move forward again.

                                                        *:ZdiffRefresh*
:ZdiffRefresh           Reload the current comparison.

ZdiffOpen, ZdiffToggle, and ZdiffRefresh are buffer-local commands. They only
exist inside the zdiff buffer that owns their review session.

CONFIGURATION                                              *zdiff-configuration*

Zdiff defines no keymaps. Configure buffer-local mappings with a FileType
autocmd if desired: >lua

    vim.api.nvim_create_autocmd("FileType", {
      pattern = "zdiff",
      callback = function(event)
        local opts = { buffer = event.buf, silent = true }

        vim.keymap.set("n", "<CR>", "<cmd>ZdiffOpen<cr>", opts)
        vim.keymap.set("n", "<Tab>", "<cmd>ZdiffToggle<cr>", opts)
        vim.keymap.set("n", "R", "<cmd>ZdiffRefresh<cr>", opts)
        vim.keymap.set("n", "q", "<cmd>bdelete<cr>", opts)

        vim.keymap.set("n", "m", function()
          if vim.b.zdiff.base == "" then
            vim.cmd("Zdiff main")
          else
            vim.cmd("Zdiff")
          end
        end, opts)
      end,
    })
<

These are suggested mappings, not defaults. Unmapped keys retain their normal
Neovim behavior.

Each zdiff buffer exposes |b:zdiff| with these fields: >lua

    vim.b.zdiff.root -- repository root
    vim.b.zdiff.base -- empty for uncommitted, otherwise the requested ref
<

Expanded hunks are syntax highlighted when Neovim can find a Treesitter parser
and highlight query for the changed file. Missing parsers, unsupported
filetypes, and unusually large patches retain the ordinary diff highlighting.
Syntax highlighting requires no zdiff configuration.

=============================================================================
MIGRATION                                                       *zdiff-migration*

No setup() call is needed. Remove require("zdiff").setup(...) from your
configuration. With lazy.nvim, also remove opts and any config function that
calls setup(). Configure mappings with the FileType autocmd above.

setup(opts) remains for compatibility with previous configurations. It ignores
all options and warns once per Neovim session. Previous mappings and features
are not restored by calling it.

To keep the previous configuration and behavior, pin the plugin to the legacy
tag. With lazy.nvim, add tag = "legacy" to your existing plugin specification
and keep your existing options. Then update zdiff through your plugin manager.
The preserved commit is 6e2a105d7cc138b25e2907589ad2c5251e608424.

See the full migration guide for removed features and configuration changes:
https://github.com/martindur/zdiff.nvim/blob/main/MIGRATION.md
